# UI Guidelines

## Christmas Theme Design System

This document defines the visual design standards for the Christmas-themed application.

## Color Palette

### Primary Christmas Colors
- **Deep Red**: `#C41E3A` - Main accent color for headers, buttons, and key elements
- **Forest Green**: `#0B5345` - Secondary accent for borders, accents, and backgrounds
- **Gold**: `#FFD700` - Highlights, decorative elements, and special accents
- **Cream/Off-White**: `#F8F8F0` - Primary background and text backdrop
- **Pure White**: `#FFFFFF` - Secondary backgrounds and card backgrounds

### Secondary Colors
- **Bright Red**: `#FF0000` - Alerts and important CTAs
- **Dark Green**: `#1B3E37` - Darker backgrounds and footer elements
- **Silver**: `#C0C0C0` - Borders, dividers, and subtle accents
- **Dark Red**: `#8B0000` - Hover states for red elements

## Typography

- **Primary Font**: System font stack or festive serif (e.g., Georgia, Garamond)
- **Heading Color**: Deep Red (`#C41E3A`) or Dark Green (`#1B3E37`)
- **Body Text Color**: Dark text on light backgrounds for readability
- **Accent Text**: Gold (`#FFD700`) for special seasonal messaging

## Component Styling

### Buttons
- **Primary Button**: Deep Red background (`#C41E3A`) with cream text
- **Hover State**: Darker red (`#8B0000`) background
- **Secondary Button**: Forest Green background (`#0B5345`) with cream text

### Backgrounds
- **Main Background**: Cream (`#F8F8F0`)
- **Card/Panel Background**: White (`#FFFFFF`) with subtle green or red borders
- **Dark Sections**: Dark Green (`#1B3E37`)

### Accents & Decorations
- **Borders**: Green (`#0B5345`) or Gold (`#FFD700`)
- **Dividers**: Silver (`#C0C0C0`) or light green
- **Highlights**: Gold (`#FFD700`)

## Visual Elements

- Include festive icons (snowflakes, ornaments, holly, candy canes)
- Add subtle patterns or textures resembling Christmas ornaments or pine branches
- Use rounded corners for a friendly, warm feel
- Apply subtle shadows and depth to create visual hierarchy

## Consistency

All UI components should follow this color palette and styling guide to maintain a cohesive Christmas-themed experience throughout the application.
